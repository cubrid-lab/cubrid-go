## v0.1.0 (2026-03-14)

Initial release of the pure-Go CUBRID `database/sql` driver and GORM dialector.

### Compatibility

- The tagged module declares Go 1.21 or newer. This first release does not establish a comprehensive live-database compatibility guarantee.
- The Go module import path is part of the historical tagged code; this notes-only correction does not rename imports or rewrite the module.

### Features

- Implement the CUBRID CAS binary-protocol driver for `database/sql`, including connections, transactions and SQL execution by @yeongseon
- Add the GORM dialector and migration support by @yeongseon

### Bug Fixes

- Handle broker port zero, CAS response framing and statement type codes correctly by @yeongseon
